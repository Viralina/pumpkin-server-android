Tentang Pumpkin Panel

Panel lokal untuk mengatur server Pumpkin langsung dari HP ini.

Satu tempat untuk serverMulai dan hentikan server di Beranda, baca log dan kirim perintah di Console, ubah pumpkin.toml di Config, lalu kelola OP dan whitelist di Pemain.
Bekerja tanpa internetSemua kontrol berjalan di perangkat ini. Hanya tombol Unduh Pumpkin di aplikasi yang memakai koneksi internet.
Token adalah kunci panelToken dibuat otomatis dan wajib dipakai. Jangan bagikan tautan yang berisi token. Ganti token kapan saja di Eksperimental → Panel web.
Buka dari perangkat lainPanel web default mati, jadi panel hanya bisa dibuka dari HP ini. Nyalakan Panel web online, pilih IP saat ini, lalu buka tautan bertoken dari HP atau laptop lain di Wi-Fi yang sama.
Alamat server terpisahAlamat panel dan alamat server Pumpkin diatur terpisah. Gunakan IP saat ini agar pemain di Wi-Fi yang sama bisa masuk, atau Localhost bila hanya untuk HP ini.
Rawat worldBuat backup world secara berkala, terutama sebelum mengganti versi Pumpkin atau memasang plugin. Backup disimpan di folder server.
Kalau panel bermasalahTutup lalu buka kembali aplikasi. Di Console tersedia tombol unduh log untuk melihat penyebab masalah.
